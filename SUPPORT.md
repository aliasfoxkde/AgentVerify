# Support

## How to Get Help

| Need | Where |
|------|-------|
| Bug report | [GitHub Issues](https://github.com/aliasfoxkde/AgentVerify/issues) |
| Wrong verification outcome | [Verification bug template](https://github.com/aliasfoxkde/AgentVerify/issues/new?template=verification-bug.yml) |
| Feature request | [GitHub Issues (feature template)](https://github.com/aliasfoxkde/AgentVerify/issues/new?template=feature_request.yml) |
| Questions / design discussion | [GitHub Discussions](https://github.com/aliasfoxkde/AgentVerify/discussions) |
| Security vulnerability | [Private security advisory](https://github.com/aliasfoxkde/AgentVerify/security/advisories/new) — never a public issue |

## Before Opening an Issue

1. Search existing issues and discussions — your question may be answered
2. Include your Rust version (`rustc --version`) and crate versions
3. For verification bugs, include the contract, the observed state, and the
   receipt — see the verification bug template for the exact format

## Response Expectations

This is an open-source project maintained on a best-effort basis. Issues are
triaged as time permits; security reports follow the timelines in
[SECURITY.md](SECURITY.md).
